# 🚀 Полное руководство по запуску проекта

## Что было реализовано

### ✅ Бэкенд (Node.js + Express + Prisma)
- REST API для персонажей и программ
- Умный калькулятор стоимости с определением конфликтов
- Система заказов с временными слотами
- Миграция данных из JSON в БД
- Документация API

### ✅ Фронтенд (Vanilla JS)
- API клиент для работы с бэкендом
- Модальные окна для выбора распределения персонажей
- Интеграция калькулятора с API
- Автоматический fallback на JSON при отсутствии бэкенда

## 📋 Запуск проекта

### 1. Запустить бэкенд

```bash
cd backend

# Установить зависимости (первый раз)
npm install

# Создать БД и таблицы (первый раз)
npm run db:push

# Импортировать данные из JSON (первый раз)
npm run seed

# Запустить сервер
npm run dev
```

Бэкенд запустится на **http://localhost:3001**

### 2. Запустить фронтенд

Вариант A: Live Server в VS Code
- Откройте `index.html` в VS Code
- Правый клик → "Open with Live Server"

Вариант B: Python HTTP server
```bash
python3 -m http.server 5500
```

Фронтенд будет доступен на **http://localhost:5500**

### 3. Тестирование

1. Откройте **http://localhost:5500** в браузере
2. Откройте консоль разработчика (F12)
3. Должно появиться сообщение: `✅ Backend connection established`

**Если бэкенд не запущен:**
- Появится: `⚠️ Backend is offline, using fallback mode`
- Данные будут загружаться из JSON файлов

## 🧪 Как протестировать модальные окна

### Тест 1: Несколько персонажей
1. Выберите 2-3 персонажа (например, Эльза, Человек Паук)
2. Выберите программу "Стандарт"
3. Должно появиться модальное окно с выбором распределения

### Тест 2: Конфликт персонажей
1. Выберите Эльзу
2. Выберите "Шоу мыльных пузырей" (дефолт: Фея)
3. Должно появиться модальное окно с вариантами

### Тест 3: Без персонажа
1. Не выбирайте персонажей
2. Выберите любую программу с defaultCharacterId
3. Должно появиться модальное окно

## 🔍 Отладка

### Проблема: "Backend is offline"

Проверьте:
```bash
# В папке backend
npm run dev

# Должно быть:
🚀 Server is running on port 3001
```

### Проблема: Модальное окно не появляется

Проверьте консоль:
```javascript
// Должно быть
✅ Backend connection established
Calculator result: {...}
```

### Проблема: Ошибка БД

```bash
cd backend

# Пересоздать БД
rm dev.db
npm run db:push
npm run seed
```

## 🎨 Кастомизация

### Изменить URL бэкенда

В `js/api-client.js`:
```javascript
window.apiClient = new ApiClient('http://localhost:3001');
```

### Изменить порт бэкенда

В `backend/.env`:
```env
PORT=3002
```

### Отключить fallback на JSON

В `js/api-client.js`:
```javascript
window.apiClient.useFallback = false;
```
